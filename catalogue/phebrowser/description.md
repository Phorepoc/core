The Phorepoc browser: tabs with a tab grid, private tabs, a light and a dark theme, the address bar at the top or the
bottom, a search engine of your choice, and downloads.

**Install an engine: WebKit or NetSurf.** The browser draws pages with a web engine that comes as its own package in
Catalogue. Install one of them (or both, and pick one in the browser's settings); without one the browser opens but
cannot show a page.

Every Phorepoc image already has the browser. This package updates it without a new image, and removing it brings back
the image's copy. It also runs on older Symbian^3 phones.
