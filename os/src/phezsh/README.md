# phezsh: zsh on the P.I.P.S. libc

zsh 5.9.2 built as `zsh.exe` (registry key `phezsh`, `phezsh.mmp`). EKA2 has no `fork()`, so zsh runs without it:
external commands are started with `posix_spawn`, subshells will re-execute zsh itself with the shell state passed
on a pipe (the BusyBox hush NOMMU pattern). There is no kernel fork and no fork emulation.

## Source

- Upstream: `https://www.zsh.org/pub/zsh-5.9.2.tar.xz`, sha256
  `36fa734374b44783582cec09bcd67822e2f992c779ec1624ab5596df078d2f81`, signature `zsh-5.9.2.tar.xz.asc` good from
  key `7CA7ECAAF06216B90F894146ACF8146CAE8CBBC4` (dana, a zsh maintainer).
- `zsh/` holds only what the build uses: the `Src/` C and header files of the core and of the static modules, the
  `LICENCE` and `README`, and the files zsh's own build generates from them (`*.pro`, `*.epro`, `*.mdh`, `*.mdhi`,
  `*.mdhs`, `bltinmods.list`, `sigcount.h`, `signames.c`, `version.h`, `patchlevel.h`, `zshpaths.h`, `zshxmods.h`).
  They were generated by zsh's own `configure` + `make` on Linux (x86-64, glibc) with
  `--disable-dynamic --disable-gdbm --disable-pcre --disable-cap --without-tcsetpgrp` and the module set below.
- `zsh/config.h` is that configure result with what the P.I.P.S. libc does not have taken out:
  `python3 port/mkconfig.py port/config.h.glibc zsh/config.h` (the list is in the script).
- Upstream files that differ from the tarball: `patches/` holds each change as a diff against 5.9.2 (all under `#ifdef PHE_NO_FORK`).

## Modules

Static (`bltinmods.list`): `zsh/main`, `zsh/rlimits`, `zsh/sched`, `zsh/datetime`, `zsh/langinfo`, `zsh/parameter`.
Left out for now: ZLE and completion (`zsh/zle`, `zsh/complete`, `zsh/compctl`, `zsh/complist`, `zsh/computil`,
`zsh/zutil`, `zsh/zleparameter`: they come with the interactive rung), `zsh/termcap`/`zsh/terminfo` (no curses in the
libc), `zsh/zpty`, `zsh/clone`, `zsh/net/socket`, `zsh/db/gdbm`, `zsh/pcre`.

## fork sites (5.9.2 `Src/exec.c`)

| Line | Function | What the child does | Plan |
|---|---|---|---|
| 309 | `zfork()` | the one funnel that calls `fork()` | `fork` is `phe_fork` (ENOSYS) until every caller is routed |
| 1864 | `execpline()` | the helper that keeps a stopped pipeline going (job control) | job-control rung |
| 2286 | `closemn()` | the tee/cat helper for `>a >b` | a copier thread or a spawned helper |
| 2808 | `execcmd_fork()` | every forked command: externals, `&`, pipeline stages, subshells | externals: `posix_spawn`; the rest: re-exec |
| 4724 | `getoutput()` | `$(...)` and backticks | `$(external)`: spawn; `$(list)`: re-exec |
| 4936 | `getoutputfile()` | `=(...)` | same as `getoutput` |
| 5014, 5042 | `getproc()` | `<(...)`, `>(...)` | needs `/dev/fd/N` |
| 5100 | `getpipe()` | process substitution as a redirection | as `getproc` |
| 465 | `zexecve()` | `execve` in the forked child or for `exec` / the last command | spawn + wait + `_exit(status)` |
