# Status-pane indicator glyphs (original art)

The status pane's indicator icons (`qgn_stat_*` in avkon.rss) that no open icon set carries. Generated by
`os/tools/statusicons/gen.py` (Etesian: 24 grid, one 2 px round stroke, outline, monochrome) and drawn in a 23-26 x 15 px cell.
pdk's `tools/mif_gen.py` searches this directory first; the other indicator icons are aliases to the Hb default theme's
status/mono icons (its `STAT_ALIASES`).
